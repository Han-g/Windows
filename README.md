# Win32 Bubble Battle

Windows API와 GDI로 구현한 2인용 물풍선 대전 게임.

| 항목 | 내용 |
|---|---|
| 저장소 이름 | Windows |
| 기술 | C, Win32, GDI, WinMM |
| 플레이 형태 | 같은 PC에서 두 플레이어 조작 |
| 빌드 설정 | Visual Studio, v143, Windows SDK 10.0 |

> 문서 기준: 2026-11-01. 구현 상태는 소스 검토 기준이며, 이 문서 갱신 과정에서 빌드·플레이·성능 실험을 새로 실행하지 않았습니다.

## 1. 프로젝트 소개

캐릭터를 이동하며 물풍선을 설치하고, 폭발과 아이템을 활용해 상대와 대전하는 게임입니다. 게임 엔진을 사용하지 않고 Windows 메시지 처리, 타이머, 비트맵 그리기, 사운드를 조합했습니다.

게임 규칙과 화면 갱신을 직접 연결한 제작 기록으로 보존합니다.

## 2. 실행·시연 방법

1. [Winpro_Proj.sln](https://github.com/Han-g/Windows/blob/main/Winpro_Proj.sln)을 Visual Studio에서 엽니다.
2. v143와 Windows SDK를 준비하고 솔루션의 플랫폼 설정에 맞춰 빌드합니다.
3. 리소스 파일을 함께 유지하고, 실행 작업 디렉터리에서 ca_bgm.wav·start.wav·win.wav를 찾을 수 있도록 합니다.
4. 실행 후 선택 대화상자에서 맵·캐릭터를 정하고 플레이합니다.

| 조작 | 플레이어 1 | 플레이어 2 |
|---|---|---|
| 이동 | W / A / S / D | 방향키 |
| 물풍선 | F | 숫자패드 0 |
| 종료 | Esc | Esc |

위 키는 main.c의 입력 처리 기준입니다. 빌드·플레이는 이 문서 작성 과정에서 실행하지 않았습니다.

## 3. 현재 구현된 기능

| 기능 | 현재 코드 |
|---|---|
| 선택 화면 | 맵·캐릭터 선택 대화상자 |
| 맵 | 타일·블록·캐릭터 배치 |
| 플레이어 | 두 캐릭터의 이동·상태 |
| 물풍선 | 설치·타이머·폭발 범위 처리 |
| 아이템 | 획득과 캐릭터 능력 관련 처리 |
| 경기 표현 | 점수·시간·비트맵·사운드 |

## 4. 담당 범위와 사용 자료

Win32, GDI, WinMM을 사용하며 비트맵·사운드 리소스를 함께 포함합니다.

개인 담당 범위와 그래픽·사운드 자료의 출처는 추가로 정리할 예정입니다. 외부 리소스의 사용 조건은 원본을 따릅니다.

## 5. 핵심 구조와 설계

```text
Windows 메시지 루프
  → WM_CREATE: 선택·리소스·맵 초기화
  → WM_KEYDOWN / WM_KEYUP: 두 플레이어 입력
  → WM_TIMER: 이동·물풍선·상태 갱신
  → WM_PAINT: 비트맵과 UI 그리기
```

주요 진입점은 [main.c](https://github.com/Han-g/Windows/blob/main/main.c)의 WndProc입니다. Character, Bubble, Object, Item 구조체로 게임 데이터를 구분하고, 타이머 메시지에서 상태를 갱신합니다. 현재는 여러 역할이 한 소스에 모여 있는 구조입니다.
